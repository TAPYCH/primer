# Padel Apsny — концепции сайта и система бронирования

Презентационная версия сайта для падел-клуба **Padel Apsny** (Сухум): три дизайн-концепции, онлайн-бронирование кортов и админ-панель для онлайн- и офлайн-броней. Это не макеты, а работающий прототип: бронь, созданная на сайте, сразу появляется в админке, а офлайн-бронь из админки сразу закрывает время на сайте.

**Демо:** https://tapych.github.io/primer/

## Демо-сценарий

1. Откройте любую концепцию → блок «Бронирование» → выберите дату, корт, время → введите имя и телефон.
2. В окне подтверждения нажмите «Открыть в админ-панели»: бронь уже в расписании со статусом «Ожидает».
3. В админке нажмите на свободную ячейку → создайте бронь «по телефону». Это время сразу станет занятым на сайте.
4. Откройте сайт и админку в двух вкладках рядом: изменения приходят вживую, с уведомлением.
5. В «Настройках» админки поменяйте цены: они обновятся на всех трёх сайтах.

## Как устроено

```
Сайт (3 концепции) ─┐
Телефон / ресепшн ──┼──► Ядро бронирования ──► Админ-панель
                    │    · единое расписание   · Telegram / SMS (боевая версия)
                    │    · защита от пересечений · онлайн-оплата (боевая версия)
                    │    · тарифы и статусы     · аналитика
```

- `assets/shared/booking-core.js` — ядро: корты, тарифы (утро / день / вечер / выходные), проверка пересечений, расчёт цены, статусы и оплаты, подписка на изменения. В демо данные хранятся в `localStorage` браузера и синхронизируются между вкладками; в боевой версии те же методы обращаются к серверному API.
- `assets/shared/booking-widget.js` / `.css` — виджет онлайн-брони, общий для всех концепций; внешний вид задаётся CSS-переменными `--bw-*`.
- `assets/shared/motion.js` / `.css` — анимации без зависимостей: появление при прокрутке, разбивка заголовков, счётчики, параллакс, магнитные кнопки, 3D-наклон, лайтбокс, бегущая строка.
- `admin/` — расписание «корты × время», список броней с фильтрами, клиенты, аналитика (выручка, каналы, загрузка по часам), настройки цен и кортов.
- `v1/`, `v2/`, `v3/` — страницы концепций; `index.html` — презентация.

Демо-брони генерируются автоматически относительно текущей даты, поэтому расписание всегда «живое». Сбросить их можно в админке: «Настройки» → «Сбросить демо-данные».

## Технологии

Чистый HTML, CSS и JavaScript без сборки и фреймворков: страницы лёгкие и быстро открываются даже на мобильном интернете. Адаптив под телефоны, планшеты и ПК; учитывается `prefers-reduced-motion`. Шрифты — Google Fonts, карта — Яндекс Карты, фото — Unsplash.

Для боевой версии предлагается: сервер на Node.js + PostgreSQL, вход персонала с ролями, Telegram-бот для уведомлений, SMS-напоминания, онлайн-эквайринг, домен и хостинг.

## Локальный запуск

Нужен любой статический сервер, например:

```bash
python -m http.server 5500
```

и открыть http://localhost:5500.
